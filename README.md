### Why won't an executor launch?

Ensure you're running the loader as Administrator. Check if your anticomponent is blocking files. Also, verify you have the required system prerequisites installed.

### Are these the latest versions of the executors?

The collection aims to include recent stable versions. Check the GitHub 'Releases' page for updates to the pack.

### Can I use this on macOS or Linux?

No. The XCutors package is built specifically for the Windows operating system.

### Where do I get scripts to run?

XCutors does not provide scripts. Users are responsible for sourcing their own Lua scripts from community forums or repositories they trust.

### The universal loader isn't working, what now?

Try restarting your computer. If the issue persists, check the 'logs.txt' file in the program directory for error details.

### Is this considered tool?

No. This is a tool collection. However, some security software may flag such tools due to their nature. Users should disable anticomponent at their own discretion and risk.
